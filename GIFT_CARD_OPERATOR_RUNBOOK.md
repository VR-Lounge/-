**Статус:** live rules + Pages (2026-11-09)  
**Оплата клиенту автоматически не списывается** — только HITL Юлии.

## Покупатель (сайт)

1. Нажимает **Подарить** (или открывает `?autogift=1`).
2. Выбирает номинал 1 000–20 000 ₽, вводит телефон, имя получателя опционально.
3. **Оставить заявку** → в Firestore создаётся `giftCards` со статусом `pending`.
4. Видит успех и код карты. Онлайн-оплаты нет — ждёт звонка.

## Юлия (CRM)

1. Увидела заявку в CRM **Подарочные карты** (фильтр «Ожидает») и/или Telegram.
2. Звонит покупателю, принимает оплату **вручную** (перевод / касса).
3. В карточке заявки: **Оплачено / активировать** → статус `issued`, баланс = номинал.
4. **Скачать карту (PDF/PNG)** или **Открыть публичную страницу** → печать / сохранить PDF → отправить клиенту (WhatsApp/Telegram/email).
5. При визите: в CRM **Списать** нужную сумму (опц. ID записи). Формулы зарплаты/выручки не трогает.

## Аннулирование

Кнопка **Аннулировать** на `pending` / `issued` / `partial` → `void`. Не списывать с void.
