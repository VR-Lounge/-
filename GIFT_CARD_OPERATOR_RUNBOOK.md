## Сценарий покупатель → Юлия → получатель

### 1. Покупатель (сайт)
1. **Подарить** (или `?autogift=1`).
2. Номинал 1 000–20 000 ₽, телефон, имя получателя опционально.
3. **Оставить заявку** → `giftCards` `pending`.
4. Ждёт звонка (онлайн-оплаты нет).

### 2. Юлия (CRM + бот)
1. Заявка в CRM **Подарочные карты** и/или Telegram.
2. Звонок → оплата вручную (перевод / касса).
3. **Оплачено / активировать** → `issued`.
4. После activate CRM предлагает **скопировать ссылку клиенту**.
5. Бот `@vr_lounge33_bot` сам пытается отправить ссылку покупателю (телефон → `clients.telegramId`).
6. Если Telegram неизвестен — бот пишет админам: «отправь ссылку» + URL + `/giftlink VRL-XXXXXX`.
7. Кнопки в карточке CRM: **Скопировать ссылку**, **Скопировать номер карты**, **Скачать PDF/PNG**, **Открыть страницу**. При списании — телефон гостя (не «ID записи»).

### 3. Клиент-получатель
1. Открывает уникальную ссылку → премиум-страница с 3D-картой (клик = переворот).
2. Видит номинал / имя / номер / баланс / историю списаний (read-only).
3. CTA: **Скачать PDF**, **Позвонить**, **Записаться** (WhatsApp).
4. В клубе называет код карты; списание делает только Юлия в CRM.

## Telegram (@vr_lounge33_bot)

| Событие | Что делает бот |
|---------|----------------|
| Новая заявка `pending` | Уведомление админам + ссылка на будущую страницу |
| Activate → `issued` (polling) | Доставка ссылки клиенту **или** текст админу «отправь вручную» |
| `/giftlink VRL-XXXXXX` | Админ: повторная доставка / получить URL |
| `/start gift_VRL-XXXXXX` | Deep link: показать ссылку |

**Путь:** Render polling в `telegram-bot.js` (без Blaze Cloud Functions). После push — рестарт Render-сервиса бота.

## Аннулирование

**Аннулировать** на `pending` / `issued` / `partial` → `void`. Не списывать с void.
