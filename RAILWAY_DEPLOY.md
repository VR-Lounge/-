## 📋 Пошаговая инструкция

### Шаг 1: Регистрация на Railway.app

1. Откройте [railway.app](https://railway.app)
2. Нажмите "Start a New Project"
3. Войдите через GitHub (используйте тот же аккаунт, что и для репозитория)

### Шаг 2: Создание проекта

1. Нажмите "New Project"
2. Выберите "Deploy from GitHub repo"
3. Выберите репозиторий: `VR-Lounge/-` (или ваш репозиторий)

### Шаг 3: Настройка переменных окружения

**Где добавлять:** В разделе **"Variables"** вашего сервиса в Railway Dashboard

**Как добавить:**
1. Откройте ваш сервис `vr-lounge-telegram-bot` в Railway
2. Перейдите на вкладку **"Variables"** (как на вашем скриншоте)
3. Нажмите кнопку **"+ New Variable"** (справа вверху)
4. Добавьте каждую переменную **отдельно**:

   **Переменная 1:**
   - **Name:** `TELEGRAM_BOT_TOKEN`
   - **Value:** `YOUR_TELEGRAM_BOT_TOKEN`
   - Нажмите **"Add Variable"**

   **Переменная 2:**
   - **Name:** `ADMIN_GROUP_ID`
   - **Value:** `-1002640127163`
   - Нажмите **"Add Variable"**

   **Переменная 3:**
   - **Name:** `ADMIN_MINI_APP_URL`
   - **Value:** `https://vr-lounge.github.io/-/telegram-miniapp.html`
   - Нажмите **"Add Variable"`

   **Переменная 4:**
   - **Name:** `CLIENT_MINI_APP_URL`
   - **Value:** `https://vr-lounge.github.io/-/client-booking-miniapp.html`
   - Нажмите **"Add Variable"**

5. После добавления всех переменных нажмите **"Deploy Changes"** (или **"Apply X changes"**)

### Шаг 4: Загрузка Firebase Service Account

✅ **Вы уже выполнили этот шаг!** Переменная `FIREBASE_SERVICE_ACCOUNT` добавлена.

**Проверка:**
- В разделе Variables должна быть переменная `FIREBASE_SERVICE_ACCOUNT`
- Значение должно быть JSON из файла `firebase-service-account.json`

### Шаг 5: Настройка команды запуска

**⚠️ ВАЖНО: Нужны настройки СЕРВИСА, а не проекта!**

**Где найти настройки:**

1. **Откройте ваш СЕРВИС** `vr-lounge-telegram-bot`:
   - Кликните на карточку сервиса в разделе "Architecture"
   - ИЛИ найдите сервис в списке слева

2. **В сервисе** перейдите на вкладку **"Settings"**:
   - Это Settings **СЕРВИСА** (не проекта!)
   - Вкладка находится вверху, рядом с "Deployments", "Variables", "Metrics"

3. В разделе **"Deploy"** найдите секцию **"Custom Start Command"**:
   - ✅ **УЖЕ УСТАНОВЛЕНО!** Показывает: `node telegram-bot.js`
   - ✅ Источник: "The value is set in railway.json"
   - ✅ **Всё правильно - ничего менять не нужно!**

4. **В разделе "Deploy" найдите "Pre-deploy Command":**
   - ⚠️ Если там написано `npm run migrate` - **УДАЛИТЕ это!**
   - ✅ Оставьте поле **пустым**
   - ✅ Нажмите "Save" или изменения сохранятся автоматически

5. **Проверьте раздел "Build" → "Providers":**
   - ⚠️ Если показывает "Staticfile" - это неправильно!
   - ✅ После обновления `nixpacks.toml` должно стать "Node.js"
   - ✅ Railway автоматически определит при следующей сборке
   - ✅ Файл `nixpacks.toml` уже обновлен с правильными настройками

**✅ Что уже настроено:**
- Файл `railway.json` содержит `startCommand: "node telegram-bot.js"` ✅
- Файл `nixpacks.toml` содержит правильные настройки Node.js ✅
- Railway автоматически подхватил эти настройки ✅

**Важно:** Если видите ошибку `npm: command not found`:
- ✅ Файл `nixpacks.toml` уже создан - это должно решить проблему
- ✅ Убедитесь, что `package.json` находится в корне проекта
- ✅ После добавления `nixpacks.toml` Railway автоматически пересоберет проект

### Шаг 6: Деплой

Railway автоматически:
1. Установит зависимости (`npm install`)
2. Запустит бота (`node telegram-bot.js`)
3. Будет автоматически перезапускать при ошибках

**⚠️ ВАЖНО: Остановите локальный процесс бота!**

После успешного деплоя на Railway:
1. Остановите локальный процесс: `pkill -f telegram-bot.js`
2. Иначе будет ошибка: `409 Conflict: terminated by other getUpdates request`
3. Telegram не позволяет запускать бота в двух местах одновременно

## 🔧 Альтернатива: Использовать .env файл

Если Railway не читает переменные из .env автоматически, создайте файл `railway.json`:

```json
{
  "$schema": "https://railway.app/railway.schema.json",
  "build": {
    "builder": "NIXPACKS"
  },
  "deploy": {
    "startCommand": "node telegram-bot.js",
    "restartPolicyType": "ON_FAILURE",
    "restartPolicyMaxRetries": 10
  }
}
```
