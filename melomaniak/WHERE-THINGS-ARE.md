# Где что лежит (для начинающих)

Коротко: **сайт в браузере** смотрит только на маленькую папку `assets/display/`. Огромный архив `from-live` (~1.5 GB) — запас на диске агента/репозитория, его страница целиком **не качает**.

## Три «места», которые часто путают

| Где | Что это | Нужно ли вам для просмотра сайта? |
|-----|---------|-----------------------------------|
| **Диск Cloud Agent (Cursor)** | Временная машина в облаке, где агент правит код. Здесь может лежать полный дамп картинок. | Нет. Это рабочая среда агента. |
| **GitHub (репозиторий)** | Код и файлы, которые закоммичены и пушатся. Ветка с редизайном — например `cursor/melomaniak-redesign-elite-7a29`. | Да, если клонируете себе. |
| **Ваш ПК** | Локальная копия после `git clone` / `git pull`. | Да — отсюда удобно открывать превью. |

Cloud Agent ≠ ваш компьютер ≠ «сайт уже в интернете». Превью локальное, пока вы сами не выложите хостинг (это отдельный HITL-шаг).

## Что внутри `melomaniak/`

```
melomaniak/
  index.html              ← сама страница (откройте через локальный сервер)
  assets-manifest.js      ← какие картинки UI реально использует
  assets/
    display/              ← КУРИРУЕМЫЙ набор (~2 MB): карточки, hero, lookbook
    from-live/            ← ПОЛНЫЙ дамп с melomaniak.рф (~1.5 GB, ~9k файлов)
    product-*.jpg/png     ← исходники импорта (UI предпочитает display/)
    logo-*.png            ← логотип
  assets-live-manifest.json / assets-live-urls.json  ← метаданные краула
  crawl_live_assets.py    ← скрипт повторного сбора (не нужен для просмотра)
  WHERE-THINGS-ARE.md     ← этот файл
  README.md               ← общее описание концепта
```

### `assets/from-live/` — что это?

Полный live-краул родного сайта: папки `hero`, `products`, `editorial`, `brand`, `misc`.  
Нужен как **архив и источник** для подбора кадров. **Не удаляйте**, если нет явной команды.  
Страница **не** должна ссылаться на все ~9k файлов — только на отобранные в `display/` / манифесте.

### `assets/display/` — что грузит браузер

Сжатые JPEG для листинга и секций (listing-*, atm-*, look-*, hero-*).  
Именно их прописывает `assets-manifest.js`. Так скролл не лагает от сырых 1920px PNG.

## Как открыть локальный превью

В терминале:

```bash
cd melomaniak
python3 -m http.server 8080 --bind 127.0.0.1
```

В браузере: [http://127.0.0.1:8080/](http://127.0.0.1:8080/)

- npm **не** нужен.
- Открывать `index.html` двойным кликом (file://) хуже: часть путей/модалки может вести себя странно — лучше сервер.
- Это **демо-концепт**: заявки не уходят, оплаты нет.

## Smoke-тест (для разработчика)

```bash
cd melomaniak
python3 -m http.server 8080 --bind 127.0.0.1 &
cd qa && npm i && node playwright-qa.mjs
```

## Что ещё нужно от человека (HITL)

- Сверка DX1+PX1: на фото читаются Smart DX1 / BX1 при листинге «DX1 + PX1».
- Цены, наличие, акции («15+ лет», Ди’Анно) — подтвердить у владельца.
- Публикация / хостинг / оплата — только после явного решения.
