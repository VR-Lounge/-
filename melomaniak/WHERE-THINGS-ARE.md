# Где что лежит (для начинающих)

Коротко: **сайт в браузере** смотрит на `assets/display/` (+ `thumbs/`) и `catalog-data.js`. Огромный архив `from-live` (~1.5 GB) — запас на диске, страница его целиком **не качает**.

## Три «места», которые часто путают

| Где | Что это | Нужно ли вам для просмотра сайта? |
|-----|---------|-----------------------------------|
| **Диск Cloud Agent (Cursor)** | Временная машина в облаке, где агент правит код. Здесь может лежать полный дамп картинок. | Нет. Это рабочая среда агента. |
| **GitHub (репозиторий)** | Код и файлы, которые закоммичены и пушатся. Ветка — `cursor/melomaniak-redesign-elite-7a29`. | Да, если клонируете себе. |
| **Ваш ПК** | Локальная копия после `git clone` / `git pull`. | Да — отсюда удобно открывать превью. |

Cloud Agent ≠ ваш компьютер ≠ «сайт уже в интернете». Превью локальное, пока вы сами не выложите хостинг (HITL).

## Что внутри `melomaniak/`

```
melomaniak/
  index.html              ← страница
  catalog-data.js         ← ~1887 товаров (листинг: имена/цены/thumbs)
  data/pdp/{id}.json      ← полные описания + specs с Woo Store API
  enrich_product_details.py ← пайплайн выгрузки PDP
  shop-app.js             ← каталог, PDP #product/slug, PhotoSwipe, бриф
  assets-manifest.js      ← hero / lookbook / gallery overrides
  CLIENT-PORTRAIT.md      ← портрет клиента (тон всех текстов)
  assets/
    display/              ← курируемые JPEG + thumbs/ для листинга
    from-live/            ← полный дамп (~1.5 GB, ~9k) — архив
```

Карточка товара (deep link): `http://127.0.0.1:8080/#product/<slug>`  
Пример: `#product/av_protsessor_anthem_statement_d2v_3d-178924`

## Как открыть локальный превью

### На Cloud Agent (Cursor)

```bash
cd melomaniak
python3 -m http.server 8080 --bind 127.0.0.1
```

`127.0.0.1:8080` доступен **только внутри VM**. Чтобы открыть у себя:

1. В Cursor: **Ports** (панель портов) → найти **8080**
2. **Forward** / Open in Browser — Cursor пробросит порт на ваш localhost
3. Откроется что-то вроде `http://localhost:8080/` у вас на машине

Без проброса портов браузер на вашем ПК до `127.0.0.1` агента не достучится.

### У себя после clone

```bash
cd melomaniak
python3 -m http.server 8080 --bind 127.0.0.1
```

Откройте [http://127.0.0.1:8080/](http://127.0.0.1:8080/)

- npm **не** нужен для просмотра.
- Это **демо-концепт**: заявки не уходят, оплаты нет. Staging: `noindex`.
